Instructions

  1. Open APK Config.
  2. Paste Server Base URL and API Token from above.
  3. Set batch size 5–10 and send delay 2000 ms.
  4. Tap Test & Register (device name is usually auto).
  5. In portal: create campaign (defaults Inactive) → Activate to allow pulls.
